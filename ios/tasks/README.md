# Compiti

Un file per compito, `T-xxx-nome.md`, scritto dal Director. Modello:

```
# T-xxx Titolo
**Assegnato a:** … **Base:** main = <sha> **Stato:** …
## Perché
## Cosa fare        (ramo indicato)
## Riuscita         (criteri misurabili)
## Non fare         (non unire, non cambiare versione né intestazione del CHANGELOG, nessuna build)
## Esito            (lo scrive chi esegue: cosa ha provato, dove, cosa resta da provare sul telefono)
```
